# מערכת ניהול תקציב למשקיע

אפליקציית Web (RTL, Mobile First) שמחליפה את קובץ האקסל "ניהול הכנסות והוצאות".

## הפעלה

פותחים את `index.html` בדפדפן (Chrome / Edge / Safari). אין צורך בהתקנה.
הגרפים וייצוא ה-Excel נטענים מ-CDN, לכן דרוש חיבור לאינטרנט. בלי חיבור, שאר המערכת עובדת והנתונים מוצגים בטבלאות.
הנתונים נשמרים אוטומטית בדפדפן (localStorage). אפשר לגבות ולשחזר אותם דרך תפריט ⋯.

## מבנה

| קובץ | תפקיד |
|---|---|
| `js/catalog.js` | קטגוריות וסעיפים (מהאקסל), סוג קבוע/משתנה/חד-פעמי, כללי הצגה לפי משק הבית |
| `js/engine.js` | **Calculation Engine**: פונקציות טהורות, ללא UI |
| `js/insights.js` | מנוע תובנות, התראות, ציון פיננסי, פוטנציאל חיסכון |
| `js/store.js` | שכבת אחסון (מוחלפת ב-API בשלב ה-Backend) |
| `js/charts.js`, `js/export.js`, `js/app.js` | גרפים, ייצוא, ממשק |
| `docs/schema.sql` | מודל הנתונים לשלב ה-Backend (משתמשים, RLS, Audit Log) |

## כללי חישוב

- שווי חודשי: חודשי = סכום · דו-חודשי = סכום/2 · שנתי/חד-פעמי = סכום/12 · משתנה = סכום 12 החודשים/12.
- תזרים: סכום שנתי או חד-פעמי עם חודש תשלום נרשם באותו חודש. בלי חודש תשלום הוא נפרס שווה על פני השנה. סכום התזרים השנתי תמיד שווה ל-12 × השווי החודשי.
- **שיעור חיסכון** = (הכנסה − הוצאות צריכה) / הכנסה. "הפקדה לחיסכון" נספרת כחיסכון ולא כצריכה.
- **יכולת השקעה** = עודף חודשי − סכום לכרית ביטחון. ברירת המחדל לכרית היא 10% מהוצאות הצריכה, וניתן לשנות אותה.
- סעיף שהוסתר לפי פרטי משק הבית (למשל שכר דירה כשמסמנים משכנתא) לא נכנס לחישוב.

## ממצא בבדיקת האקסל

בשורה 57 ("פיננסים") הנוסחה היא `=SUM(B49:B56)`. לכן שתיים משלוש שורות "החזר הלוואה" (B47:B48) לא נכללות בסיכום הקטגוריה ובסך ההוצאות.
בשאר הקטגוריות טווחי ה-SUM מלאים. החישוב במערכת מוגדר מחדש ואינו תלוי במיקום תאים.

## מה נשאר לשלב הבא

- Login, הרשאות והצפנה בצד שרת: דורשים Backend. המבנה מוכן ב-`docs/schema.sql`, וההחלפה נעשית רק ב-`store.js`.
- חיבור אוטומטי למידע פיננסי (שלב 3 במפרט).
